# NutriRx 🩺🍎

A simple static website that gives **food-based diet suggestions** for common health problems — built as a college mini project using **HTML, CSS, and JavaScript**.

## What it does

Select a health condition (like Heart Problem, Diabetes, High BP, Thyroid, etc.) from the dropdown or the quick-select chips, and the site instantly generates a **prescription-style card** showing:
- ✅ Foods to eat
- ❌ Foods to avoid
- 📝 A short dosage/diet note

## Health conditions covered 

Heart Problem, Diabetes, High Blood Pressure, Obesity, Anemia, Digestive Issues, Thyroid, Kidney Disease, Liver Disease, Arthritis, Skin Problems, Hair Fall, Cold & Immunity, Migraine, Insomnia, PCOS, Asthma, Uric Acid/Gout, Bone Weakness, Stress & Mental Wellness etc...

## Tech used

| File | Purpose |
|---|---|
| `index.html` | Page structure |
| `style.css` | Design (prescription-pad theme) |
| `script.js` | Condition data + logic to render the food prescription |

No frameworks, no build tools — just open `index.html` in a browser (or run with VS Code Live Server).

## How to run

1. Download/clone this repo
2. Open the folder in VS Code
3. Right-click `index.html` → **Open with Live Server**
